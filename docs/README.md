# Angry Birds Clone

## Install
```
npm install
```

## Run frontend
Serve `index.html` with any static server or run `npm run dev` for Vite.

## Run backend
```
node backend/server.js
```

## Features
Phaser 3 single-player with levels, AI pigs, TNT, scoring, editor, admin dashboard, and Express backend for auth, billing, achievements, and TON simulation.
